# Progression Specification v0.1

상태: 사용자 확정 성장 구조를 바탕으로 한 구현 초안. 6→18개, 자산 보존, 딜러 6명 조건 제외는 확정 사항이다. 가격·해금 문턱·운영 예비금 시간·정리 절차는 이번 제안이다.

## 1. 첫 완성본의 시작과 종료 지점

시작: 1단계 매장, 테이블 1개, 일반 딜러 1명, 600G. 자동 방문과 정상 세션 정산이 시작된다.

검증 종료 지점: 2단계 매장으로 리모델링한 뒤 7번째 테이블을 구매하고 배치하여 일반 영업을 시작한다. 기존 6개 테이블과 모든 보유 직원이 유지되어야 한다.

완성본에서는 2단계 매장의 18개 설치 지점과 반복 구매를 지원한다. 중규모 대회를 실제 개최할 수 있어야 하며, ‘추후 업데이트’ 버튼만 제공하는 것으로 해금을 구현했다고 보지 않는다. 다만 18개까지의 전체 경제 밸런스와 중규모 운영은 이번 계산 검산을 통과한 항목이 아니다.

## 2. 성장 구간과 의도

| 구간 | 가능한 행동 | 이해해야 할 관계 | 눈에 보이는 변화 |
|---|---|---|---|
| 테이블 1개 | 자동 영업 관찰, 기본 투자 | 세션 완료가 매출로 이어짐 | 입장·착석·진행·완료 |
| 테이블 2개 | 추가 딜러 고용·배치 | 설치와 운영은 다름 | 미운영 표시가 영업 표시로 바뀜 |
| 테이블 3개 | 숙련 딜러 비교, 소규모 대회 준비 | 수요·처리 능력·대회의 관계 | 테이블을 대회용으로 전환 |
| 테이블 4~6개 | 서비스와 시설 투자, 대회 반복 | 혼잡·만족도·순이익의 균형 | 매장 밀도와 활동 증가 |
| 리모델링 | 조건과 비용·운영 예비금 확인 | 성장이 다음 공간을 해금함 | 단층에서 2층 건물로 변화 |
| 테이블 7개 이상 | 새 층 확장, 직원 추가·재편성 | 커진 상권에 맞춘 투자 | 새 층의 첫 테이블 영업 |

이 순서는 튜토리얼의 설명 순서이며 모든 구매를 강제로 따라야 하는 퀘스트 순서는 아니다. 수요가 부족할 때 추가 딜러 고용을 강요하지 않는다.

## 3. 초기 가격표 — 제안

| 구매 대상 | 비용 |
|---|---:|
| 2번째 테이블 | 1,200G |
| 3번째 테이블 | 2,400G |
| 4번째 테이블 | 4,200G |
| 5번째 테이블 | 7,000G |
| 6번째 테이블 | 11,000G |
| 7번째 테이블 | 16,000G |
| 8~18번째 테이블 | 아래 공식 |
| 일반 딜러 추가 고용 | 400G |
| 서비스 직원 고용 | 600G |
| 편의시설 1레벨 / 추가 2레벨 | 1,000G / 2,500G |
| 1→2단계 리모델링 | 15,000G |

8~18번째 테이블 가격 초안: `ceil(16000 × 1.3^(테이블 번호 - 7) / 100) × 100G`.

위 값들은 운영 구조를 시험하기 위한 값이다. 8~18번째 가격 곡선과 플레이 시간은 아직 검증하지 않았다. 테이블 자체의 개별 레벨업은 첫 검증 버전에 포함하지 않는다. 편의시설 개선으로 시설 업그레이드 효과를 먼저 확인한다.

일반 구매에는 잔액 부족을 검사하고, 구매 후 4게임시간 운영비 미만이면 경고한다. 충분한 잔액이 있는데 경고만으로 구매를 막지는 않는다. 대회와 리모델링의 운영 예비금 조건은 별도 필수 검사다.

## 4. 해금 — 제안

| 해금 대상 | 조건 | 해금 이후 별도 실행 조건 |
|---|---|---|
| 일반 딜러·서비스 직원 고용 | 시작 시 | 고용비 보유 |
| 지역 홍보 | 시작 시 | 400G, 인지도 40 미만, 대기 시간 종료 |
| 편의시설 업그레이드 | 테이블 2개 설치 | 구매 비용 |
| 숙련 딜러 1명 | 테이블 3개 설치 | 대기 직원 목록에서 배치 |
| 소규모 대회 | 테이블 3개 설치, 인지도 10 | 딜러 2명과 테이블 2개 예약 가능, 모집·비용 조건 |
| 대회 전문 딜러 1명 | 소규모 대회 1회 정상 완료 | 대기 직원 목록에서 배치 |
| 리모델링 기능 | 시작부터 조건 목록 표시 | 아래 필수 조건 모두 충족 |
| 중규모 대회·두 번째 테마 | 2단계 도달 | 대회는 4테이블·4딜러와 모집·비용 조건 |

해금과 실행 가능 여부를 분리한다. 예를 들어 중규모 대회가 해금됐더라도 실제 배치 가능한 딜러가 3명이면 ‘딜러 1명 추가 필요’로 표시한다. 해금 보상은 해당 기록 ID로 한 번만 지급한다.

## 5. 리모델링 조건

확정 조건을 구체화하는 검증용 문턱:

1. 1단계 매장에서 테이블 6개 설치.
2. 인지도 50 이상.
3. 소규모 대회 정상 완료 2회 이상.
4. 예약·정리·진행 상태의 대회가 없음.
5. 현금으로 리모델링 15,000G와 정리 기간 비용, 전환 후 최소 운영 예비금을 확보.

딜러 6명, 서비스 직원 특정 인원, 특정 테마, 특별 직원 보유는 필수 조건이 아니다. 미운영 테이블도 설치 개수에 포함한다. 근무 딜러가 3명인 상태에서도 다른 조건이 맞으면 리모델링할 수 있어야 한다.

```text
T = 현재 일반 세션이 모두 끝날 때까지의 최대 잔여 게임시간
C_before = 정리 동안 발생할 시간당 비용의 보수적인 상한
C_after = 기존 배치를 새 매장에 유지했을 때의 시간당 운영비
필요 현금 = 15000 + T × C_before + 4 × C_after
```

정리 동안 발생할 매출을 조건 충족 자금으로 미리 계산하지 않는다. 기존 배치가 일반 딜러 6명·서비스 직원 1명이면 C_after는 760G/게임시간, 전환 후 예비금은 3,040G이다. T가 2시간이면 정리 비용까지 포함한 필요 현금은 최대 19,560G이다.

건물 위 버튼과 성장 화면이 같은 판정 함수를 사용한다. 버튼에는 비용 외에도 부족한 조건을 표시한다. 조건 충족 뒤 단순 현금 변동이 발생할 수 있으므로 실행 시 다시 검사한다.

## 6. 리모델링 상태 전환

`일반 영업 → 리모델링 준비 → 자산 전환 확정 → 새 매장 영업`

### 요청과 준비

- 요청 시 조건을 다시 검사하고 고유 작업 ID를 만든다.
- 15,000G를 사용 불가 자금으로 잠근다. 나중에 한 번만 실제 리모델링 비용으로 확정한다.
- 새 테이블 구매, 직원 배치 변경, 추가 지출, 대회 예약은 준비 완료까지 잠근다.
- 신규 방문 생성을 멈추고 기존 대기는 안내 후 해산시킨다. 공사 안내에 따른 해산을 서비스 불만으로 계산하지 않는다.
- 착석 중인 손님은 정상 세션을 끝내고 정해진 매출을 발생시킨다. 정리 중 급여와 운영비는 계속 낸다.
- 만족도는 준비 기간 고정한다. 일반 세션 완료에 따른 인지도와 매출은 정상 반영한다.
- 진입 시 충족한 인지도·실적 조건을 준비 중 재평가해 취소하지 않는다. 준비 상태에서도 저장·복원이 가능해야 한다.

### 자산 전환

- 모든 일반 세션이 완료되면 하나의 전환 작업으로 단계와 설치 지점 매핑을 변경한다.
- 테이블·직원·시설의 기존 ID와 레벨·보유 상태를 보존한다.
- 현금, 인지도, 만족도, 직원 보상 수령 기록, 대회 실적·개최권 사용 기록, 홍보 대기 시간, 게임 시각을 보존한다.
- 현재 테마는 유지하고 두 번째 테마를 선택 가능 상태로 해금한다.
- 기존 6개 테이블을 1층의 대응 설치 지점으로 배치한다. 가능한 기존 직원 배치를 유지하고 대기 직원은 대기로 유지한다.
- 2층 지점 7~18을 구매 가능 상태로 연다. 테이블은 무료로 추가하지 않는다.
- 잠근 비용을 소비하고 리모델링 완료 ID를 저장한다. 같은 ID를 다시 처리해 비용·해금이 중복되지 않게 한다.

### 연출과 재개

건물 확장 연출은 경제 전환 결과를 표현한다. 연출 완료 콜백으로 자산을 지급하지 않는다. 연출을 건너뛰거나 도중에 앱을 닫아도 동일한 매장을 복원해야 한다.

전환 완료 다음 경제 분부터 2단계 수요와 기존 배치로 영업한다. 준비 시간은 세션에 따라 달라지며 별도의 현실 시간 공사 대기는 추가하지 않는 안이다.

## 7. 배치·층·테마

1단계는 검증된 6개 설치 지점, 2단계는 1층 6개·2층 12개의 설치 지점을 가진다. 아래층의 입구·바·서비스 공간을 고려한 배치도는 Visual Bible에서 검증한다. 통로 폭과 실제 에셋 크기는 아직 확정하지 않았다.

테이블을 구매하면 다음 빈 설치 지점에 테이블·의자·딜러 위치를 묶어 생성한다. 임의의 좌표에 놓는 기능은 제공하지 않는다. 구매 직후 근무 가능한 미배치 일반 딜러가 있으면 자동 배치하고, 특별 딜러는 플레이어가 명시적으로 편성한다. 자동 배치 동작은 화면에 알려준다.

7번째 테이블은 2층의 첫 설치 지점이다. 새 층 전환 버튼과 안내로 구매 결과를 바로 확인하게 한다. 첫 버전의 기본 화면은 층별 보기로 제안하며, 두 층의 경제는 항상 함께 계산한다. 보고 있지 않은 층의 영업을 멈추지 않는다.

1단계 기본 테마 1종, 2단계 추가 테마 1종을 최소 범위로 제안한다. 구체적인 미술 스타일은 미정이다. 테마 변경은 설치 지점·충돌·직원 배치·세션·경제 능력치를 변경하지 않는다.

이동 시간은 첫 버전에서 경제 처리 시간을 지연시키지 않는 연출이다. 길찾기 오류로 매출이 멈추지 않아야 하며, 시각적인 경로 오류 자체는 별도의 비주얼 결함으로 수정한다.

## 8. 첫 완성본의 필수 검증

| ID | 시나리오 | 통과 조건 |
|---|---|---|
| P01 | 새 게임 시작 | 1테이블·1딜러·정해진 자금에서 자동 영업과 정산 |
| P02 | 딜러 없는 새 테이블 구매 | 설치 성공, 미운영 원인 표시, 허위 처리 능력 증가 없음 |
| P03 | 수요가 충분한 상황에서 딜러 추가 | 배치 후 운영 능력·실제 완료 이용객 변화 |
| P04 | 수요가 낮을 때 딜러 추가 | 투자 예상치가 추가 비용과 제한적인 매출 효과 설명 |
| P05 | 숙련·대회 전문·서비스 직원 편성 | 각 효과가 정해진 범위에만 적용, 능력 중복 없음 |
| P06 | 소규모 대회 | 일반 세션 정상 정리, 자원 예약, 비용·보상 단일 정산 |
| P07 | 6테이블·3딜러로 조건 충족 | 직원 6명 조건 없이 리모델링 가능 |
| P08 | 진행 중 대회에서 리모델링 요청 | 이유를 설명하고 차단 |
| P09 | 비용만 있고 예비금 없음 | 부족 자금 설명, 상태와 자산 변경 없음 |
| P10 | 정상 리모델링 | 보유 테이블·직원 ID 집합 동일, 새 단계·한도·해금만 의도대로 변경 |
| P11 | 준비·전환·연출 중 각각 재접속 | 유실·중복 지급·이중 차감 없이 완료 또는 재개 |
| P12 | 7번째 테이블 구매 | 2층 배치, 직원 배치, 세션 시작·완료 및 매출 |
| P13 | 18번째·19번째 테이블 구매 시도 | 18개까지 유효 배치, 19번째 차단 |
| P14 | 테마·층 전환 | 모든 경제 상태와 설치 한도 유지 |
| P15 | 중규모 대회 | 실제 예약·정리·개최·정산 가능 |

위 표는 향후 제품 구현의 인수 기준이다. 이번 문서 작성 과정에서 제품 테스트가 통과했다는 의미가 아니다.
