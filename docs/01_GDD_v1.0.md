# 홀덤펍 타이쿤 — GDD v1.0

상태: 사용자가 확정한 첫 번째 개발 기준의 정리.

## 1. 게임의 정체성

**작은 동네 펍에서 세계적인 포커 대회장까지.**

플레이어는 자동으로 운영되는 홀덤펍의 사장이다. 직접 포커를 플레이하지 않는다. 손님은 자동으로 방문하고, 딜러와 서비스 직원은 담당 업무를 수행한다. 플레이어는 매장의 운영 상태를 확인하고 필요한 곳에 투자한다.

첫 설계 원칙: **플레이어가 매장의 운영 상태를 분석하고, 가장 필요한 곳에 투자해 성장을 만들어낸다.**

자동 영업과 방치 중 성장은 중요한 편의 요소다. 동시에 모든 업그레이드가 항상 같은 비율로 수익을 증가시키는 구조는 피한다.

## 2. 플레이어의 주요 행동

1. 수요·처리 능력·수익·서비스 상태를 확인한다.
2. 테이블을 구매하고 직원을 고용·편성한다.
3. 시설을 개선하고 취향에 맞는 테마를 선택한다.
4. 대회를 개최해 수익과 인지도를 얻는다.
5. 조건을 달성하면 리모델링한다.

일반적인 손님 응대, 착석, 딜링, 이용 완료는 자동으로 진행된다. 직접 의자를 옮기거나 손님마다 행동을 지시하는 조작은 핵심 플레이에 포함하지 않는다.

## 3. 두 가지 성장 구조

- 매장 내부 성장: 테이블 추가 → 직원 고용·편성 → 시설 개선 → 운영 결과 변화.
- 매장 단계 성장: 현재 매장 성장 → 리모델링 → 공간·시설·대회 확장 → 새로운 운영 목표.

전체 게임은 장기적으로 6단계 매장 성장을 지향한다. 3~6단계의 정확한 시설 한도와 콘텐츠는 아직 확정하지 않았다.

## 4. 경제의 기본 단위

| 항목 | 정의 |
|---|---|
| 게임 내 시간 | 현실 시간과 분리된 경제 계산용 시간 |
| 방문 수요 | 게임 내 1시간 동안 방문하려는 손님 수 |
| 운영 테이블 | 딜러가 배치되어 실제 영업 가능한 테이블 |
| 운영 좌석 | 현재 영업 중인 테이블의 전체 좌석 |
| 이용 세션 | 착석부터 정상적인 이용 완료까지의 과정 |
| 완료 이용객 | 이용 세션을 정상 완료한 손님 |
| 매출 | 정상 완료한 이용 세션에서 확정된 수익 |
| 순이익 | 매출에서 급여·시설 운영비 등 해당 비용을 뺀 금액 |

첫 버전의 정상적인 이용 세션은 정해진 매출을 발생시킨다. 중도 퇴장, 추가 주문, 개별 재방문 고객은 이후 확장한다. 착석 전 대기를 포기한 손님은 완료 이용객이 아니다.

게임 내 시간과 현실 시간의 배율은 테스트로 조정한다. 실제 포커의 핸드 수를 기본 경제 단위로 사용하지 않는다.

## 5. 시스템 간 관계

방문 수요가 처리 능력보다 낮으면 수요 확보의 가치가 높아진다. 수요가 처리 능력을 초과하면 테이블·딜러·효율 개선의 가치가 높아진다. 서비스 품질은 만족도에, 만족도와 인지도는 방문 수요에 영향을 준다.

대회는 일반 영업과 테이블·직원을 공유하며 비용과 인지도 보상을 가진다. 대회 참가비 전체를 순이익으로 처리하지 않는다.

운영 화면은 수치와 원인을 함께 설명한다. 투자 전후의 예상 변화와 실제 결과는 같은 경제 규칙을 사용해야 한다.

## 6. 시설과 테마

시설은 자동 배치한다. 테이블과 의자·딜러 위치를 함께 배치하고 이동 통로를 확보한다.

테마는 플레이어의 취향을 표현한다. 테마 변경으로 테이블이 사라지거나 설치 한도·기본 운영 구조·이동 가능 여부가 달라져서는 안 된다. 기본 테마의 외형과 경영 효과를 가진 시설 개선을 분리한다.

테마를 적용하면 벽·바닥뿐 아니라 테이블, 의자, 카운터, 조명, 장식, 간판을 일관되게 변경한다.

## 7. 직원

첫 검증 버전에는 일반 딜러, 숙련 딜러, 대회 전문 딜러, 서비스 직원을 포함한다. 직원 편성에 따라 실제 운영 결과가 달라져야 한다.

직원 가챠는 첫 검증 버전에서 제외한다. 정식 게임에서는 주요 콘텐츠로 유지한다. 직원별 외형, 등급, 스킬, 육성, 중복 획득, 보장 규칙은 추후 별도로 설계한다.

기본 직원만으로도 운영과 성장을 진행할 수 있어야 한다. 실제 매장에서 직원의 개성을 확인할 수 있어야 한다.

## 8. 첫 번째 리모델링

| 항목 | 1단계 | 2단계 |
|---|---|---|
| 이름 | 동네 홀덤펍 | 인기 홀덤펍 |
| 건물 | 작은 단층 | 확장된 2층 |
| 테이블 상한 | 6개 | 18개 |
| 대회 | 소규모 데일리 토너먼트 | 중규모 토너먼트 해금 |
| 인테리어 | 기본 테마 | 추가 테마·장식 해금 |

조건은 테이블 6개 설치, 일정 인지도, 소규모 대회 개최 실적, 리모델링 비용과 최소 운영 자금 확보다. 딜러 6명 고용을 필수 조건으로 삼지 않는다.

진행 중인 대회가 있으면 리모델링할 수 없다. 기존 테이블·직원·육성·보유 자산은 유지한다. 기존 테이블 6개를 새 매장에 자동으로 배치하고, 이후 7번째부터 추가 구매한다.

## 9. 첫 플레이 가능한 완성본

테이블 1개와 기본 딜러로 시작해 자동 영업, 투자, 대회, 매장 성장, 1→2단계 리모델링을 경험하고 확장된 매장에서 다시 영업할 수 있어야 한다.

2단계에서 추가 구매와 운영이 실제로 작동해야 한다. 테이블 상한 18개는 데이터와 배치 구조에 반영한다. 첫 핵심 검증은 7번째 테이블의 구매·배치·영업까지 수행한다.

세계 대회, 3단계 이후 건물, 정식 가챠, 대규모 직원 육성은 후속 범위다. 첫 완성본은 정식 출시 준비가 끝났다는 의미가 아니다.

## 10. 품질 원칙

- 실제 경제와 투자 예상치의 계산 규칙을 공유한다.
- 화면 프레임·이동 애니메이션과 경제 시간을 분리한다.
- 자산이 저장·불러오기·리모델링 중 유실되거나 중복되지 않아야 한다.
- 원인을 알 수 없는 수익 감소와 설명 없는 성장 제한을 피한다.
- 확정된 규칙, 제안 수치, 아직 결정하지 않은 사항을 구분해 관리한다.
